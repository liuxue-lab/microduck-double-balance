# 文档发布验证范围

本次检查针对文档、增量 Git 对象和本地导入器。详细结果随发布包提供，
不将这些静态检查当作新一次 HIL 或完整上游 CI。

- 三份原始报告的 SHA256 与固定来源一致，期限、周期、动作对照和范围标记一致。
- 229 项清单的期望与观察值、逻辑字节数、169 份内容的去重统计一致。
- 新增与改动 Markdown 的相对链接按原项目检查器的解析规则核对；
  原有目标按固定父提交的完整 Git 树核对，新目标按实际文件核对。
- Git 增量范围限定于根 README、新实验入口、本目录和独立文档发布工具；
  训练、控制、推理、依赖配置和旧标签不在变更范围内。
- 导入器在隔离测试仓库验证快进、重复执行、拒绝分歧、标签冲突、脏工作树、
  新路径冲突、符号链接冲突及包损坏；不冲突的未跟踪文件须保持原字节。
