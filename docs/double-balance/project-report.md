# Microduck 双球平衡项目总报告

更新日期：2026 年 10 月 25 日（Asia/Shanghai）

交付范围：PC 原生 MuJoCo 与 Jetson Orin Nano Super 的实时硬件在环验证

## 项目结论

Microduck 脚踩篮球、上球直接接触原头壳的冻结策略，已完成电脑仿真与真实 Orin 推理硬件组成的闭环。最终系统采用 200 Hz 原生 MuJoCo 物理计算、50 Hz 控制和 FP32 ONNX 推理。开启实时三维窗口后，两个固定工况各完成 3,000 个控制周期，均没有超过 20 ms 截止时间；完整周期最大值分别为 15.310057 ms 和 14.675660 ms。

两组均完成 60 秒双球保留，未触发原始掉落终止。该结果允许整体平移，几何稳定门限也有短暂越界：稳定采样比例分别为 99.7667% 和 96.0000%。因此，已完成的是本报告定义的有界仿真 HIL 交付，并不包含严格连续接触、位置保持或物理机器人验收。

核心代码最新版本为 `056657aa36158fb81dca6fd2092e525222d6e632`，用户已确认推送成功。总报告、统一复现说明及归档范围核对已完成：本机采集记录的 229 个固定资产全部通过哈希核对，已有字节数期望也匹配。完整历史目录扫描及异地备份仍有明确范围缺口，见第 10 节。本目录将总报告、复现说明和证据索引纳入源码；功能基线不变，文档发布范围见 [发布说明](publication.md)。

## 2 系统架构与计算职责

| 环节 | 执行位置与职责 | 数据约定 |
| --- | --- | --- |
| 物理与观测 | PC 项目 Python 环境，原生 MuJoCo CPU | 5 ms 物理子步，4 个子步组成一个 20 ms 控制周期 |
| ROS 桥 | PC 系统 Python 3.10 与 ROS2 Humble | 将当前观测发送至 Orin，并返回匹配回复 |
| 策略推理 | Orin 系统 Python 3.10、ONNX Runtime CPUExecutionProvider | 冻结 FP32 ONNX、归一化及 LSTM 状态；各回合按协议复位 |
| 参考对照 | PC 原冻结 PyTorch Actor | 与 Orin 请求重叠计算，逐一比较全部实际应用动作 |
| 三维显示 | PC 独立进程、独立物理 CPU 核 | 目标 25 fps，接收状态并更新几何；物理步进与策略推理均为 0 |
| 证据记录 | PC 各次独立 run 目录 | 状态 NPZ、模型 MJB、耗时 CSV、扰动轨迹、通信记录与报告 |

每个周期先取得匹配的 Orin 回复并通过动作对照，再将该动作应用到仿真。不存在本地动作替代或过期动作复用。无效字段、非有限数、错误会话、模型、序号或请求摘要均会被拒绝。三方通信链式摘要用于核对同一次会话的一致性。

原生 `MjData` 使用 float64，任务和策略张量保持 float32。原 BAM 执行器模型及 2 ms 虚拟延迟时钟保留，6/8/10/12 ms 延迟输出由 5 ms 物理求解步进行零阶保持采样。这不等于在 2 ms 时间网格重新积分，也不表示策略经过 FP64 重训。原 actor 噪声、归一化、延迟和历史处理保持原约定；85 维 critic 属于原训练接口，当前推理周期省略不参与动作计算的 critic 与奖励计算。

## 4 评估工况与判据

两个工况均使用环境种子 `2026102407`。`quiet-2407` 不施加外力；`regression-2500` 使用扰动种子 `2026102500`，向 `trunk_base` 惯性质心施加世界坐标系水平随机方向力。

抗扰力为机器人自重的 10%。本次机器人质量为 0.7427010536 kg，重力加速度为 9.81 m/s²，标称力为 0.7285897336 N。扰动从第 2 秒至第 58 秒，每 2 秒一次，每次持续 0.1 秒，共 29 次；每次覆盖 20 个 5 ms 子步，共 580 个受力子步。方向、时序、力向量、冲量和清零均纳入报告审计。

功能通过条件包含回合时长、原始掉落判据、策略和输入不变、实际动作逐一对照以及逐子步模型边界审计。关节越界会记录并永久使验收失败；配置中的电流、PWM、施加力矩越界或非有限状态触发相应停止。这里的电流是执行器模型估计，未验证真实热额定值、独立最大转速或整机安全姿态包络。

实时指标采用从固定释放时刻到周期完成时刻的 `release_to_finish_ms`，覆盖通信等待、参考对照、物理、审计、状态采集与发送。首周期计入，不跳过周期，也不平移后续截止时间。ROS 往返、Orin 推理和显示状态年龄属于分项指标，不能替代完整周期指标，也不能简单相加以重新定义完整周期。

通信协议的 1 秒硬响应超时用于处理失联；它与 20 ms 实时截止判据不同。超出 20 ms 的周期即使随后收到回复，也不能获得实时通过。本报告只说明两次已完成测试没有发生这种期限违约。

## 8 已完成的性能处理

原生后端直接读取当前关节地址映射的 qpos/qvel，保留原 BAM 模型和动作合同，并将物理计算固定为 CPU 原生 MuJoCo。推理阶段只计算动作所需的 actor 观测，省略 critic 与奖励统计；策略及归一化参数不变。

PC 冻结参考推理与 Orin 请求重叠执行，控制、ROS 桥和显示分配到独立物理核。无窗口控制运行使用实际 Actor 实例和实际初始观测预热 128 次，随后恢复 RNG、LSTM 和权重状态，再开始全部正式周期计时。这个处理解决了前一次运行中首周期参考推理冷启动造成的期限失败，正式首周期没有被删除。

实时显示在独立进程中工作。控制阶段暂停循环垃圾回收并在结束后恢复，引用计数保持正常；控制结束后统一导出必要数据。所有优化效果以表中的完整周期实测为准。
