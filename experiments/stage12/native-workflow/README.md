# Stage12 原生仿真训练与模型选择归档

本目录保存 2026-10-20 已实际执行的原生 PPO 工作流、有限微调、评估恢复、模型取回和本机回放代码，以及用户回传的小 JSON。当前演示与后续开发基准是 `native-speed-refine-v1/refine_000500.pt`，即原 4500 模型加速度奖励微调 500 次，策略累计 5000 次。

这是已执行的独立实验工作流归档。运行入口和包源码保持原始字节，不把训练覆盖代码重新注册为新的核心任务，也不改写已通过回放核对的 365 份冻结源码、依赖、物理参数、观测和原评估标准。远端 Stage11 基线缺少其中 48 份既有源码，且 `mdp.py` 仍是旧版本；本机封口同时把这些已存在且 SHA 匹配的源码纳入提交。已提交的匹配版本直接复用，其余本机改动不混入。后续任务模块重构应作为新的开发变更处理。

## 结果

| 模型 | 首回合连续稳定至少 5 秒 | 连续稳定时长中位数 |
|---|---:|---:|
| 原训练 4500 | 212/256（82.81%） | 7.80 秒 |
| 原训练 6000 | 165/256（64.45%） | 5.77 秒 |
| 速度奖励 +250 | 246/256（96.09%） | 9.44 秒 |
| **速度奖励 +500，选定** | **253/256（98.83%）** | **9.48 秒** |
| 速度奖励 +750 | 245/256（95.70%） | 9.27 秒 |
| 速度奖励 +1000 | 250/256（97.66%） | 9.31 秒 |

原奖励的低学习率微调先完成了 500 次更新，两个候选为 198/256、208/256，未超过原 4500；随后速度奖励微调完成 1000 次预算。不能把两轮的同名检查点混为一谈。选定的是 +500，末尾 +1000 继续保留。

速度奖励只改变 `double_balance` 项：原位置/高度/直立因子乘以上球相对速度高斯项（标准差 0.08 m/s）和脚下球水平速度高斯项（0.15 m/s），权重仍为 4。其他奖励、观测和物理保持不变；评估和回放使用原任务与原阈值。不同奖励版本的总奖励均值不能作为同一量表直接比较。

比较使用相同配置和种子标签的独立批次，历史初始指纹不一致记录保留；不宣称严格逐初态配对。253/256 是选择集结果，三个失败回合没有补采样。没有新增最终留出评估，也不宣称旧 G11 严格物理验收、ONNX 或实机验收通过。当前用户目标是仿真。
